# Pre-Entrega N° 2: Módulo 3 - Data Science II (Machine Learning para la Ciencia de Datos)
## 👤 Autor: Gabriela Mazzocchi

## 🎯 Objetivo del Proyecto
El objetivo principal de esta entrega es aplicar técnicas de adquisición de datos desde múltiples fuentes (como archivos .csv y .xlsx) para consolidar un dataset limpio, unificado y listo para el análisis explortatorio o modelado de Machine Learning, haciendo uso principal de la librería pandas.

## 🛠️ Tecnologías y Librerías Utilizadas
Lenguaje: Python

Librerías principales: pandas para manipulación, limpieza y consolidación de datos, openpyxl / xlrd para la lectura e integración de archivos Excel.

Entorno de desarrollo: Google Colab.
